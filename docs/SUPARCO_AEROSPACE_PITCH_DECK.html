The Problem

CNC Manufacturing Information is Scattered

Engineers waste hours hunting across three incompatible formats. Our system automates cross-validation and detects silent flaws before machining begins.

1. Excel Manufacturing Record

Contains stock size, finished dimensions, machine assignments, operation setup/run times, tooling, and lot quantities.

Challenge: Banners, merged cells, varying column headers

2. PDF Engineering Drawing

Specifies nominal tolerances, title blocks, revision histories, material callout notes, and GD&T dimensioning.

Challenge: Inch vs mm, rotated text, scanned image PDFs

3. 3D Model (IGES / STEP)

Defines true mathematical 3D boundary representation (B-Rep): oriented bounding box, hole diameters, and cylinder counts.

Challenge: Multi-body solids, surface-only files, off-axis holes
System Architecture

Deterministic Geometry + Verified LLM

We do not ask the LLM to hallucinate measurements. All geometry and table facts are extracted deterministically with Python and passed as strict verifiable context.

INGEST

Schema-Agnostic Table Extraction

Autonomous header sniffing and row alignment. Handles banner offsets (Job Cards B), numeric/text part codes, and multi-sheet workbooks.

Python · OpenPyXL · Canonical Column Mapping
CAD

OpenCascade (OCP) 3D B-Rep Kernel

Measures exact oriented bounding boxes (OBB), groups cylindrical surfaces by axis to detect holes vs bosses, and computes true solid volume.

OpenCascade · Build123d · IGESControl & STEPControl
VERIFY

Evidence-Grounded Answering Gateway

Cross-checks values with tolerance and unit conversion. If an answer is missing or contradicted, it reports citations or raises a flagged mismatch.

FastAPI · Pydantic Verification · Cell-level Citations
Production Deployment Stack
  • Backend: FastAPI with Async SQLAlchemy & Psycopg 3
  • Database: PostgreSQL (storing part fragments & cell refs)
  • Streaming: Server-Sent Events (SSE) live response proxy
  • Frontend: Next.js 16 with Tailwind & React 19
  • CAD Engine: OpenCascade Python wrapper (`OCP 7.7.2`)
  • LLM Gateway: Multi-provider failover (Claude Code, Anthropic, Groq, with offline rule fallback)

Rigorous Evaluation

Automated 42-Question Evaluation Harness

The codebase includes a comprehensive golden evaluation suite in backend/evals/golden.jsonl evaluated by an automated scoring harness.

Multi-Row & Ordered Lookups

Includes adversarial tests: malicious user prompt injections and poisoned remarks cells in spreadsheets. The verifier isolates data from instructions.
Ground Truth Isolation
Answer keys are sequestered in backend/evals/answer_keys/ so file discovery cannot leak answers into LLM prompts.
