## Excel record
Row `9001` in [`../real_world_records.xlsx`](../real_world_records.xlsx) (sheets `Parts` + `Operations`,
same layout as `data/mfg_record_A.xlsx`), generated by `tools/make_real_world_records.py`.

**Planted mismatch:** Excel says `8 x Ø15 (4 per flange)` in the Holes column *and* in Ops 40/50;
the 3D model has 12 (6 per flange). Must be flagged. Flange OD, bore, PCD and envelope all
agree and must NOT be flagged. Answer key: `backend/evals/answer_keys/ground_truth_real_world.json`.

## Why it's a useful test
- Multi-body STEP (app must not assume one solid).
- Two flanges facing different directions (hole counting off-axis).
- Free-form S-bend → axis-aligned bbox ≠ true envelope.
- No usable drawing PDF → app must say the drawing is unavailable/unreadable.
